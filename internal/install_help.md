Instalação recomendada no Windows

1) Git
   winget install --id Git.Git -e

2) Ollama
   winget install --id Ollama.Ollama -e

3) Aider
   py -m pip install -U aider-chat

4) Modelos recomendados
   ollama pull qwen2.5-coder:7b
   ollama pull qwen3-coder:30b

5) Dica para comunidade
   - modelo rápido: qwen2.5-coder:7b
   - modelo forte: qwen3-coder:30b
   - o modelo forte é opcional para PCs mais fracos
